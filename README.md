
# KC Cheap Flights PH

A responsive promotional website for KC Cheap Flights PH, showcasing domestic flight deals around the Philippines and providing direct contact links for travel inquiries.

## Features

- Responsive design for desktop and mobile
- Domestic flight promotion cards
- Philippine destination highlights
- Facebook Messenger inquiry link
- WhatsApp inquiry functionality
- Email and telephone contact links
- Mobile-friendly navigation

## Built With

- HTML5
- CSS3
- JavaScript

## Important Information

Flight prices displayed are sample promotional listings and are not live airline inventory or real-time fare quotes.

Please contact KC Cheap Flights PH to confirm current fares, availability, travel dates, and booking conditions.

All fares are subject to availability and may change anytime.
