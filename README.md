
# KC Cheap Flights PH

A responsive promotional website for KC Cheap Flights PH, showcasing domestic flight deals around the Philippines and providing direct contact links for travel inquiries.

## Features

- Responsive design for desktop and mobile
- Domestic flight promotion cards
- Philippine destination highlights
- Facebook Messenger inquiry link
- WhatsApp inquiry functionality
- Email and telephone contact links
- Mobile-friendly navigation

## Built With

- HTML5
- CSS3
- JavaScript

## Project Structure

kc-cheap-flights-ph/
├── index.html
├── style.css
├── script.js
└── README.md

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in your browser.
4. Alternatively, use the Live Server extension.

## GitHub Pages Deployment

This website can be hosted for free using GitHub Pages.

1. Open repository Settings.
2. Select Pages.
3. Choose Deploy from a branch.
4. Select the main branch.
5. Select /(root).
6. Click Save.

## Important Information

Flight prices displayed are sample promotional listings and are not live airline inventory or real-time fare quotes.
